# Dialysis Center

Modern, patient-focused Dialysis & Renal Healthcare website and Patient Dashboard built with HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5 CDN, and Bootstrap Icons.

## Key Pages
- `index.html` — Home & Clinical Overview
- `about.html` — Mission, Clinical Standards & Milestones
- `services.html` — Hemodialysis, Peritoneal Dialysis, Nocturnal & Vascular Care
- `care-team.html` — Multidisciplinary Nephrology & Nursing Team
- `patient-dashboard.html` — Interactive Patient Portal (Scheduling, History, Lab Records, Billing, Notifications, Profile)
- `pricing.html` — Insurance & Coverage
- `first-time-guide.html` — First-Time Dialysis Guide
- `blog.html` — Renal Health Education
- `contact.html` — Contact & Clinic Locations
- `login.html` / `register.html` — Patient Portal Authentication
- `404.html` — Error Page
